# Villa Feronia

Sito ufficiale / vetrina per Villa Feronia,
Castel Rigone – Lago Trasimeno – Umbria.

## File del progetto

Il progetto contiene:

- index.html
- style.css
- script.js

## Pubblicazione su GitHub Pages

### 1. Crea il repository

Su GitHub crea un nuovo repository.

Puoi chiamarlo:

villa-feronia

### 2. Carica i file

Carica nella cartella principale:

index.html

style.css

script.js

### 3. Attiva GitHub Pages

Vai su:

Settings

poi:

Pages

In:

Build and deployment

seleziona:

Deploy from a branch

Come branch seleziona:

main

Come cartella:

/ (root)

Poi premi:

Save

Dopo qualche minuto GitHub pubblicherà il sito.

## Importante

Questa versione utilizza GitHub Pages e quindi è un sito statico.

Il modulo non salva automaticamente le prenotazioni
in un database.

Il cliente invia la richiesta tramite WhatsApp
e il gestore deve confermare la disponibilità.

## Google Maps

Il sito contiene un pulsante per aprire la posizione
di Villa Feronia su Google Maps.

## Immagini

Le immagini attualmente utilizzate sono caricate
da URL esterni.

Per avere un sito completamente indipendente,
puoi scaricare le immagini, inserirle in una cartella:

images/

e modificare i relativi percorsi nell'HTML.
